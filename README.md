# ai-llm-takip
AI/LLM gelişmeleri takip listesi ve raporlar (otomatik güncellenir).

- **Çalışma ritmi:** 17 Ekim 2026'dan itibaren 3 günde bir. Öncesinde haftalıktı (raporlar 2026-08-17 – 2026-10-12).
- **Raporlar:** `raporlar/YYYY-AA-GG.md`. Dosya adı çalışma tarihidir; her rapor bir önceki rapordan bu yana geçen dönemi kapsar.
- **Kalıcı durum:** `takip-listesi.md`. Kurallar, aktif/arşiv konular ve değişiklik geçmişi bu dosyadadır.
